# 305331 Computer and Information Security — Weekly HTML Lecture Slides

Static, offline-capable lecture slides for the 15-week NU 305331 teaching sequence.

- [Open the slide index](index.html)
- Week 1 is the current teaching-ready exemplar: 27 slides with full instructor notes and source traceability.
- Weeks 2–15 remain visible on the index as review/development status and are not published as finished lecture files.
- Textbook chapter decks are maintained separately and are not mixed into this weekly teaching site.

Use Arrow keys or Space to navigate. Press `N` for speaker notes, `F` for fullscreen, and `P` to print/export to PDF.
