# 305331 Computer and Information Security — HTML Chapter Slides

Static, offline-first HTML slide decks for NU course 305331, organized as the 12 textbook chapters.

- [Open slide index](index.html)
- Chapter decks: Chapter 01–12
- The public chapter order is generated from the 15-week teaching plan using the course chapter mapping.
- The old `week-NN.html` public URL namespace has been retired to avoid confusion with textbook chapters.

Use the arrow keys or Space to navigate. Press `N` for speaker notes, `F` for fullscreen, and `P` to print/export to PDF.
